## Native Universal Search authority

GoreeCloud Launcher owns the user-facing Universal Search experience, native provider framework, core local indexing required for the Launcher experience, aggregation/ranking, permission-aware categories, actions, commands, shortcuts, recents/history when implemented, contextual behavior, and standardized provider APIs. Core Launcher Universal Search must remain usable when GoreeCloud Index and GoreeCloud Search are absent, disabled, unavailable, or not production-ready.

GoreeCloud applications and platform services may register searchable resources, actions, shortcuts, commands, and supported metadata only through versioned, explicitly governed provider contracts. Those contracts must define provider identity, resource/action schemas, authorization and privacy requirements, freshness, ranking metadata, offline behavior, cancellation/timeouts, failure isolation, and compatibility/versioning.

GoreeCloud Search and GoreeCloud Index remain separately developed systems. They may later integrate as optional advanced providers/backends without transferring Launcher Universal Search ownership. Historical Index-oriented revisions remain valid provenance for those exact revisions only.

## Planned next capabilities

- Continue the Launcher-owned Universal Search provider fabric beyond installed apps and trusted local actions: versioned provider registration, permission/privacy metadata, additional local sources, richer result/action schemas, bounded partial/streaming presentation where justified, recents/history with explicit user control, commands, shortcuts, and optional Search/Index providers.
- Validate User Apps/Work Apps behavior on representative hardware with a real secondary/work/Shelter profile: profile creation/removal, availability/unavailability, package install/update/remove/suspend, same-label apps across profiles, isolation, switching, launch correctness, and no cross-profile leakage through search, previews, widgets, suggestions, backup, or recovery.
- Perform representative-device performance review of the PR #180/#182 source line: Home-to-drawer latency, icon readiness, first-open versus warm-open behavior, scroll/page smoothness, frame timing/jank, memory pressure, battery/power impact, and any OEM-specific behavior. Emulator transition-performance evidence remains diagnostic only.
- Extend workspace editing from the PR #176/#177 foundations into mature cross-page drag/drop, folders/smart folders, organization, group actions, and process-death-safe undo/recovery.
- Add Android AppWidgetHost, searchable widget gallery, resize/configuration, widget stacks, first-party Glaze Cards, and provider crash containment.
- Add user-defined categories/tags/collections, explicit custom ordering, and locally derived recent/frequent views only when transparent, user-controlled, and free of behavioral tracking.
- Complete Launcher-specific GLAZE UI V1.6 rendered, accessibility, adaptive phone/tablet/foldable, reduced-effects, contrast, scalable-text, performance/power, rollback, and Human Visual Excellence acceptance.
- Complete evidence-backed runtime integration for all applicable Integral Platform Systems and keep authority boundaries explicit.
